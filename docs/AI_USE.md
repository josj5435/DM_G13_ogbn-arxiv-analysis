# AI 사용 공개

| 도구·제공자 | 사용 범위·영향받은 작업 | 확인 가능한 모델·시기 |
| --- | --- | --- |
| Codex · OpenAI | 코드 구현, 데이터 획득·전처리, 환경 구성, 실험 실행, 테스트, 표·그림, 지표 검토, 문서·검증 지원. src·tests·configs 및 README·docs·data 안내·handoff, 실험 산출물 생성에 영향 | GPT-6 Astra. 2026년 11월 6~9일 |
| ChatGPT · OpenAI | 방법론 검토, 구현·실험 결과 점검, 수정 방향 검토. 방법 문서, 실험·평가 설계, 결과 해석에 영향 | GPT-6. 방법론 설계 및 구현·결과 검토 단계에 사용 |
| Claude · Anthropic | 코드·결과·문서의 외부 교차 검토와 오류 지적. 지표 정의, 결과 해석, README·docs·검증·인계 문서에 영향 | Claude Opus 5.5. 2026년 11월 6~9일, 구현·결과·문서 검토 단계에 사용 |

검증에는 손계산한 작은 예제, NetworkX의 독립 PageRank, scikit-learn의 NDCG/PCA/k-means, Apriori 완전열거, 미래 데이터 변경에 대한 학습 입력 불변성, 저장된 예측·지표의 교차 비교를 사용했습니다. 규칙 적용 비율과 fallback 구분, 추천 길이 제한, 평균 순위 진단, 동적 요약과 파일 무결성도 테스트합니다. 현재 실행 가능한 범위는 [검증 요약](../VALIDATION.md)에 있습니다.

수치는 실험 CSV/Parquet에서 산출하며, 데이터·알고리즘 설명은 공식 문서·원 논문·강의자료를 근거로 합니다. AI의 검토 의견만으로 정확성을 확정하지 않으며, AI 출력은 학술 출처로 사용하지 않습니다.

본 팀은 2026년 11월 6~9일 동안 코드 구현·실험 실행·문서 작성을 위해 OpenAI Codex(GPT-6 Astra)를, 같은 기간 코드·결과·문서의 교차 검토와 결과 해석·참고문헌 보완을 위해 Anthropic Claude(Claude Opus 5.5)를, 방법론 설계와 결과 검토를 위해 OpenAI ChatGPT(GPT-6)를 사용했습니다. 도움받은 부분은 src·tests·configs의 코드, README·docs·data 안내·handoff 문서, outputs의 실험 산출물입니다. 단위 테스트, 제출본 검사, 저장 결과의 독립 재계산, 참고문헌의 원출처 대조로 출력을 검증했으며, 교차 검토에서 지적된 결과 요약의 고정 수치, 문서 편집 시 실패하던 제출 검사 규칙, 누락된 원 논문 인용을 수정했습니다. 제출한 작업에 대한 책임은 본 팀에 있습니다.
