# 방법·실험 설정·수업 대응

## 문제와 데이터 흐름

OGB의 ogbn-arxiv [1], [11]에서 출판연도 제한 인용망을 만들고 세 과제를 독립적으로 평가합니다. 과거 인용에 기반한 미래 인용 순위(PageRank), 내용 유사성에 기반한 군집(k-means), 일부 보이는 참고문헌에 기반한 복원(Apriori)입니다. PCA는 군집 특징의 차원 비교입니다. 데이터 정리 → 시간 snapshot/마스크 → 2017 검증 선택 → 설정 동결 → 2018 최종 평가 → 표·그림 순서이며 서로 다른 과제의 점수를 합치지 않습니다.

## 데이터 준비와 시간 제한

논문 169,343개, 128D 특징, 출판연도, 40개 분야 라벨, 방향 인용 1,166,243개를 사용합니다. 노드 ID는 원본 행 번호이며 arXiv ID가 아닙니다. 텍스트는 node ID→MAG ID로 연결합니다. 유효 출판연도는 정수 1800~2026이며, 범위 밖 끝점·자기 인용·중복·미래 논문을 인용하는 연도 역전을 검사합니다. 실제 제거는 연도 역전 20,903개이고 정리된 간선은 1,145,340개입니다. 동일 연도 인용은 허용합니다. 특징의 유한성·양의 L2 norm을 군집 적격 조건으로 사용합니다.

| 단계 | 학습에 접근 가능한 논문/인용 | 평가 |
| --- | --- | --- |
| Validation | 출판연도 ≤2016, 69,499개 노드/226,954개 간선 | 2017년 |
| Final | 출판연도 ≤2017, 90,941개 노드/361,979개 간선 | 2018년 |

이 분할은 OGB 분류 리더보드의 공식 split과 다릅니다. 모델 선택은 2017년에만 합니다. 분야 라벨은 군집 선택에 사용하지 않고 2018 ARI의 외부 진단으로만 사용합니다. 전처리·마스크 seed는 `configs/validation.yaml` 및 저장된 `frozen.json`에 있습니다. 고립 노드·빈 basket도 학습 모집단에 남깁니다.

## PageRank

PageRank [13]는 source→target을 인용하는→인용받는 방향으로 유지합니다. 희소 전이 행렬에 대해 균등 초기 확률에서 `p_next=α(Pᵀp+dangling_mass/N)+(1−α)/N`을 반복합니다. L1 변화≤1e−8, 최대 1,000회이며 미수렴은 실패 처리합니다. α 후보 0.70/0.85/0.95 중 검증 NDCG@100 최대를 선택하고 동률이면 0.85에 가까운 값, 작은 값을 우선합니다. 선택 α=0.7입니다.

동일한 과거 후보 노드 전체에 대해 다음 해 내부 인용 수 c의 `r=log2(1+c)`를 relevance로 사용합니다. `DCG@K=Σ r_i/log2(i+1)`의 **선형 gain** NDCG [15]이며 IDCG는 동일 후보 전체의 relevance를 정렬합니다. 공식 순위 동률은 node ID 오름차순입니다. Spearman은 점수와 미래 인용 수의 상관입니다. Baseline은 동일 인용망 In-degree입니다. 사례 진단은 두 점수의 Average Rank 차이를 쓰며 공식 NDCG 규약과 구별합니다.

## k-means·PCA

각 유효 논문 특징을 float64 L2 정규화합니다. PCA는 학습 논문에만 fit하는 full SVD, whiten=False이며 PCA 이후 추가 정규화는 하지 않습니다. 원본 d=128은 PCA를 사용하지 않습니다. scikit-learn [7]의 k-means++ [18]/Lloyd [19], n_init=10, max_iter=300, tol=1e−4를 사용합니다.

검증 후보 k={20,40,60}, d={16,32,64,128}, seed=0입니다. PCA 후보는 학습 누적 설명분산≥90%여야 합니다. 같은 평가 논문 2,000개(seed=101)의 **원본 정규화 128D 공간**에서 모든 후보의 Silhouette [16]을 비교합니다. 최고 Silhouette−0.01 이상인 적격 후보 중 작은 d, 작은 k를 우선합니다. 선택은 k=20,d=128입니다. 사전 후보 집합에서의 선택이며 전역 최적이 아닙니다.

최종은 (선택 k, 모든 d)와 (모든 k, 선택 d)의 합집합 6개 설정에 seed=0~4를 적용한 30개 모델입니다. 같은 k의 원본 128D가 Baseline이며 선택 모델과 같으므로 개선으로 세지 않습니다. ARI [17]는 분야 라벨과의 일치도입니다. 크기 보존 무작위 배정 5회, seed 간 ARI, 설명분산·재구성 오차·거리 분포·비용도 제공합니다.

## 인용 패턴과 시각화

군집을 보지 않고 참고문헌 길이 교차층에서 최대 100,000쌍을 고정(seed=202)하고 모든 모델과 무작위 기준에 공유합니다. 각 쌍의 일반 Jaccard `J=|A∩B|/|A∪B|`를 계산합니다. 이는 두 논문이 참고문헌을 공유하는 정도인 bibliographic coupling [22]을 정규화한 값입니다. 그룹 평균은 `Σ(wJ)/Σw`, `w=1/쌍 포함확률`인 **포함확률 역수가중 평균 Jaccard**입니다. 항목별 min/max 가중을 쓰는 Weighted Jaccard Similarity가 아닙니다. 직접 인용의 같은 군집 비율은 참고문헌 길이층 내 source 군집을 섞은 기준과 비교합니다. 연관성은 인과나 추천 정확도가 아닙니다.

관계 그림은 seed=42로 선택한 군집 3개·논문 5개의 부분 뷰입니다. 최대 80노드/250방향간선, 부분추출 seed=43, 배치 seed=44·100회입니다. 노드 면적은 전체 snapshot PageRank를 q99에서 제한하며 색은 내용 군집입니다. 표시 표본을 평가 모집단으로 사용하지 않습니다. `visualization/`에 실제 노드·간선·좌표·설정을 제공합니다.

## Apriori와 평가

학습 논문의 내부 과거 참고문헌을 set basket으로 만듭니다. 같은 basket에 함께 나타나는 두 논문은 co-citation [23] 관계입니다. M에는 빈 basket도 포함합니다. 1차 항목 빈도로 L1을 만들고 L1 항목 쌍만 2차 집계하여 L2를 구하는 pair-only Apriori입니다. 길이≥3 itemset이나 복합 antecedent를 학습한 것으로 설명하지 않습니다. support=count/M, confidence=count(a,b)/count(a), lift=confidence/(count(b)/M)입니다 [6].

기본 count 100/200/500과 확장 20/50을 confidence 0.10/0.20/0.30과 비교합니다. 확장은 평가 점수를 보기 전 train-only 집계의 1,800초·8GiB RSS 제한으로 결정합니다. A2의 마스크 5개 평균 Recall@10 최대, 그다음 NDCG·큰 count·큰 confidence로 선택합니다. 선택은 count=20, confidence=0.1입니다.

평가 연도 논문 중 내부 과거 참고문헌≥5인 질의만 포함합니다. seed=0~4로 `max(1,floor(0.2×참고문헌 수))`개를 숨기고 나머지를 제공합니다. 후보는 동일한 과거 노드 전체이며 보이는 참고문헌과 자기 자신을 제외합니다. 규칙 점수는 적용 규칙의 최대 confidence, 동률은 학습 빈도 내림차순·node ID 오름차순입니다.

| 방법/지표 | 정의 |
| --- | --- |
| B2 | 전체 후보의 학습 인용 빈도 인기순 |
| A2 | Apriori 규칙 후보만 Top10 |
| A3 | A2를 먼저 두고 부족한 자리를 같은 인기순으로 보충, 최대 10개 |
| Recall@10 | Top10 적중/전체 숨긴 정답. 비빈발 정답도 분모에 포함 |
| Precision@10 | 적중/10. 짧은 목록도 분모 10 |
| NDCG@10 | 이진 hit의 log 할인/이상적 할인합 |
| RuleCoverage | A2/A3에 규칙 후보가 있는 적격 질의 비율. B2=N/A |
| query_has_applicable_rule(_rate) | 같은 동결 규칙 집합에 조건부인 질의 진단. B2가 규칙을 사용했다는 뜻이 아님 |
| fallback | A3의 추천 항목이 인기순 보충인지. 규칙이 있는 질의에도 적용 가능 |
| empty / catalog coverage | 빈 목록 질의 비율 / 후보 전체 중 한 번이라도 추천된 항목 비율 |

빈 추천도 0점으로 평균에 포함합니다. 2018년 포함률은 15,072/29,799=50.6%이며 전체 논문 성능이 아닙니다. 표준편차는 초기화·마스크 변동이며 독립 표본 신뢰구간이 아닙니다.

## 환경과 해석의 경계

실험 환경·실행시간·RSS는 각 stage의 environment.json과 지표 표에 있습니다. 시간은 wall time, RSS는 전체 프로세스 표본 최대치로 순수 알고리즘 추가 메모리가 아닙니다. 큰 시간 관측도 포함해 평균·중앙값·범위를 함께 제시합니다. OGB 제공 특징은 MAG [12] 코퍼스의 skip-gram 임베딩 [14]을 바탕으로 하며, 역사적 학습 시점은 보장되지 않습니다. PageRank의 낮은 성능, 제한적인 군집 품질, PCA 개선 미입증은 이 데이터와 평가 조건에서의 결과로 해석합니다. 근거 수치와 오류 사례는 [결과 해석](ANALYSIS.md)에 있습니다.
